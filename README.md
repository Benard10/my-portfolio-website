# Benard Okello — Geospatial Portfolio

A modern personal portfolio website for Benard Okello, a Geospatial Analyst and Research Specialist based in Nairobi, Kenya.

The site presents selected geospatial work across spatial analysis, remote sensing, land administration, infrastructure mapping, aviation GIS, dashboards, automation, and web GIS.

## Live Sections

- Hero profile and professional summary
- About section
- Geospatial capabilities
- Filterable project case studies
- Delivery process
- Experience timeline
- Contact and WhatsApp project-intake form

## Built With

- HTML
- CSS
- JavaScript
- Responsive static-site architecture
- Optimized WebP imagery
